# Zoomcast 0.1.5

Optional offline transcription and captions. In the editor, open Captions,
download caption support once, then generate a transcript from microphone,
system audio, or both. Correct text and timing, change caption appearance,
export SRT/VTT, and include captions in exported MP4s. Saved projects preserve
the transcript and style. Subtitle timing follows cuts, clip order, and audio sync.

The speech engine and model are downloaded only on request, outside the installer.
No API key, subscription, or audio upload is needed. Download cancellation,
integrity verification, and removal are available; removing speech files keeps
saved captions. Review recognized text and captions around partial-sentence cuts.

Includes the cursor/appearance and editable clip-timeline changes from the active
development branch, together with the published 0.1.4 shortcut fix.

Run native Windows typecheck, lint, tests, build, and `npm run verify:captions`.
The caption guard uses an isolated profile and a synthetic spoken test recording.
Its first run downloads the real upstream engine and model. It checks offline
recognition, text correction, Ctrl+S, visibility, reopen, SRT/VTT, reordered export,
audio retention, and speech-file removal. Test evidence belongs in tmp, outside
the installer. `npm run verify:caption-package` repeats these checks in a separate
packaged validation app with bundled FFmpeg and no development overrides.
`npm run verify:parity` also compares captioned preview/export frames with reordered clips.
Validate the packaged application before publishing.
