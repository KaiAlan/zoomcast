# Bundled media tools

Zoomcast builds FFmpeg 9.0.2 from the exact commits in `ffmpeg.lock.json`. External codec dependencies are x264, zlib, NVIDIA codec headers and AMD AMF headers. FFmpeg and x264 sources are unmodified. Optional dependency autodetection is disabled. All other media components come from FFmpeg's source tree. The GPU runtimes come from the user's installed Windows drivers and are not shipped.

The accompanying `zoomcast-ffmpeg-source-<app-version>.zip` contains the complete FFmpeg, x264 and zlib source archives, NVIDIA headers, all AMF headers used by the build, original licenses and compiler runtime notices, this lock file, the build/download scripts, actual build configuration, toolchain information and binary SHA-256 hashes. Distribute that archive alongside its matching installer, with access for every recipient. Retain the exact archive for previously distributed versions. Recipients may redistribute the GPL components and their sources under their original licenses; repository privacy does not restrict those rights. No written source offer is substituted for the actual source archive.

To rebuild on Windows x64, install native Node 24 and MSYS2 MINGW64 with `make`, `mingw-w64-x86_64-gcc` and `mingw-w64-x86_64-pkgconf`. Set `MSYS2_LOCATION` to the MSYS2 installation directory if it is not `C:\msys64`, then run `node prepare-ffmpeg.cjs` from this extracted source package. Its lock file and shell script must be in the same directory. Archives and headers are already present; downloads occur only for missing or invalid inputs. NASM is pinned and checksum verified. The actual compiler/package versions used for this release are in `toolchain.txt`. The standard Windows/MSYS2 toolchain is not itself a bundled media component. Toolchain downloads and sources: https://www.msys2.org/ and https://github.com/msys2/MINGW-packages.

This rebuild uses the exact media sources and configuration, but does not promise byte-identical executables across different toolchain versions, installation paths or build dates. `ffmpeg-buildconf.txt`, `ffmpeg-config.mak`, and `x264-config.mak` record the release build. Source archives contain upstream license notices; AMF and NVIDIA header notices are also retained. FFmpeg with x264 is GPL-2.0-or-later. Source/build packaging follows the availability guidance at https://ffmpeg.org/legal.html.
